# 来源和迁移关系

输入资料为用户提供的 `ymnmr-master.zip`，其中项目标识为 `ym-login-plug:1.1.5`，归档 SHA-256：`c053f88b1c2582a68e56ab5e9f07adede11af6f61e2e7312ac308490e4da1b3a`。

原样资料没有修改。新工程复用其业务账号/证书/应用资源的配置含义，提供精确账号映射的导入工具；新增标准 TLS DEMO 认证、服务端会话、资源授权和原生 C/S 通路。新模块不是对厂家真实 UKey 能力的实现声明。

未把原闭源 cipher-client SDK、第三方接入客户端、驱动或真实密码凭据纳入本发行包。真实 SDK 的适配与使用条件待试点选型确认。

原网页插件的 JavaScript 注入及旧布尔验签接口不作为新 C/S 服务的认证依据；旧 Web 入口尚未迁移到新授权流程。迁移前必须保留原行为回归证据并验证如何约束旧入口，不能以新增服务存在代替整个系统改造完成。

新增 Java 运行模块使用 JDK 标准库。Maven 构建插件与 JUnit 测试依赖的名称和版本在 POM 中固定；发行 JAR 不包含这些构建/测试依赖。

DEMO 自行生成的 CA 与软件私钥不属于任何真实机构 PKI，也不随二进制包分发。软件与商密产品/协议的适用和合规判断仍以选定真实组合及系统方案为准。
