# 本地增强验证

本工具用于没有真实 C/S、UKey 或国密环境时，验证新增 DEMO 的流传输、访问控制和进程生命周期。它使用真实 Java 独立进程、TCP 和 TLS 软件证书；业务协议、身份、网络拓扑仍属于演示范围。

## 运行

源码先构建（当前 37 项 JUnit 测试）：

```sh
python3 tools/manage.py build
python3 tools/manage.py acceptance --seconds 60
```

二进制包无需 Maven，直接运行第二条。Windows 用 `python` 替换 `python3`。这不是 Windows 实机已经验证的声明。

每次生成新的 `.runtime/acceptance-时间戳/`，自动生成演示证书、随机口令，选择未占用的回环端口。可用 `--dir <新目录>` 指定输出目录，已有非空目录拒绝覆盖。目录含生成的测试私钥和口令，仅 JSON 报告和必要日志用于共享。

`--seconds` 控制混合负载阶段，允许 5–1800 秒；默认 60 秒。可设置 1800 进行更长的本地检查。全套运行还包含证书准备和故障注入阶段，因此总耗时更长。只结束自己启动的子进程，不修改防火墙、路由、系统证书库或系统 Java。

## 检查内容

| 范围 | 操作和判定 |
|---|---|
| 流传输 | 分段写入登录帧、合并写入多个命令、UTF-8 回显、2 MiB 二进制逐字节比较 |
| 半关闭 | 客户端发完请求后关闭发送方向，仍须完整收到 2 MiB 响应 |
| 并发 | Alice/Bob 两个 Agent、两个负载进程，共 6 条长连接；持续检查身份、回显和二进制内容 |
| 连接反复建立 | 两个身份、4 个并发工作线程合计 200 次连接/登录/QUIT，随后继续故障测试，验证容量可以复用 |
| 业务故障 | 强制结束业务服务后访问失败；原端口重启后现有 Agent 可建立新业务连接 |
| Agent 故障 | 强制结束 Agent 后本地端口与已有连接关闭；新 Agent 重新认证后恢复 |
| 接入服务故障 | 强制结束接入服务后已有连接关闭、无回落通路；重启后旧会话被拒，显式重新认证后恢复 |
| 正常退出 | 通过 stdin 的 `disconnect` 指令撤销会话，检查服务端撤销审计、本地端口及已有连接关闭 |
| 有效期 | 4 秒测试会话到期后原生客户端连接关闭，Agent 正常退出 |
| 原路径 | 直接访问业务端口，若成功则明确记录 `OBSERVED_GAP` |
| 同机借用 | 独立进程使用已授权 Agent 端口，若成功则明确记录 `OBSERVED_GAP`；该进程仍须提供允许的业务账号和密码 |

强制结束进程使用平台的进程终止操作，证明的是该类崩溃/断连行为，不等于已经模拟真实网络黑洞、丢包和 TCP 重传。

JUnit 另覆盖：真实产品调用路径的服务端主机名校验、无/错/过期/未登记证书、跨证书会话、资源授权、异常/重复/超长 CONNECT 头、明文/TLS 1.2 降级拒绝、未完成握手超时、持续慢速发送的绝对建立期限、连接上限及恢复、并发身份隔离、撤销与建连竞争、会话/登记对象容量、服务重启、日志口令检查等。

## 报告解读

`acceptance-result.json` 含各项证据、时长、负载统计、资源快照和清理结果；详细日志/探针 JSON 在 `acceptance-logs/`。

- `PASS`：实现的检查满足本次预期。
- `OBSERVED_GAP`：确认了尚未解决的安全边界，不能计为安全验收通过。
- `FAIL`：实现的检查不满足预期，命令以非零状态退出。
- `overall_status=CHECKS_PASSED_WITH_GAPS`：检查完成且保留明确缺口。
- `production_ready=false`：本工具始终如此标识，退出码 0 不能解释为真实商密/生产验收通过。

负载的一个校验循环包括 WHOAMI、UTF-8 ECHO 和一次 256 KiB BLOB 往返；字节数仅统计 BLOB 两个方向的业务字节，不含 TLS/协议开销。P50/P95/最大延迟按每个探针分别统计，覆盖上述循环，不含初次登录和循环间 50 ms 间隔。连接反复建立的延迟另含登录。它们是本机演示记录，不能外推现场容量。

POSIX 上存在 `ps` 时每约 10 秒记录自有服务进程 RSS，包含 JVM 热身和 GC 波动。短时快照不能证明无内存泄漏；未设置目标系统的性能验收阈值，不宣称已通过性能或长期稳定性验收。

## 当前边界

业务服务和 Agent 都只绑定回环地址。跨机器防火墙隔离、同机 OS 用户/进程授权、真实驱动和 PIN、国密协议与吊销、GUI、Windows/Linux 实机、安装升级和多小时稳定性仍待验证。

当前 BLOB/LOGIN 仅是自带业务协议；本工具不证明任意 HIS、政务程序、数据库协议或已有加密业务都能透明接入。原网页方案也没有在这次改动中完成迁移。
