| `README.md` | 本地部署和测试说明 |

### 确认账号输入框规则

本机 JAR 内的 `extractUsernameFromInput()` 按 `key=value&key=value` 解析输入框属性。裸值 `username` 不包含等号，无法得到匹配条件；取不到账号时，拦截脚本会跳过 PIN 校验，不能据此判断 UKey 登录成功。

在原业务登录页右键账号输入框，选择“检查”，查看对应的 `<input>` 标签：

- 若实际有 `id="username"`，填写 `id=username`。
- 若实际有 `name="username"`，填写 `name=username`。
- 若没有上述属性，使用页面实际存在且唯一的属性组合，例如 `type=text&placeholder=请输入账号`；该值只是格式示例。

只需核对标签属性，不要复制账号、密码、PIN 或输入框的 `value`。截图本身不能证明账号输入框具有上述任何属性。
