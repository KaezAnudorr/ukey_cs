# C/S UKey 登录增强：新增工作入口

目标是在本地 C/S 客户端点击登录后，暂停本次业务请求，弹出 PIN 认证窗口，调用真实 UKey 签名并由服务端验证；成功后继续原登录，取消或失败则停止。

## 当前可以使用什么

- `../ukey/`：已有 C/S DEMO 源码，要求 Java 17+，已在本机 JDK 21 上构建并通过 37 项测试。使用软件证书进行 TLS 1.3 双向认证，不调用真实 UKey。
- `../web-plugin/`：网页登录插件的现有启动脚本、配置、参考 JS 和说明。原厂 JAR、部署 PDF 仅保留在本机，不随公开源码上传。
- `tests/environment/Java8DeviceProbe.java`：Java 8 调用现有本地 UKey 助手的只读设备探测。它不输入 PIN，不执行签名。
- `tests/results/`：本次本机实验的脱敏结果，不含测试口令和证书私钥。

**尚未实现：客户端点击登录触发真实 PIN 窗口、UKey 签名验签以及继续/拒绝该次登录。** 现有 DEMO 的成功不等于这些功能已完成。
